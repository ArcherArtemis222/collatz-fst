## Falsifiers

### (a) Ranking function 與其自身轉移表矛盾【引文核對：已核實】

Def 4.17（Cycle Distance Ranking）在 60 個局部狀態
`S = {0,…,9} × {0,1} × {0,1,2}` 上定義
`ϱ(s) := min{k ∈ ℕ₀ ∣ δ^(k)(s) ∈ 𝒞}`；
Lemma 4.18（Monotonic Descent）宣稱每次轉移
`ϱ(s_{i+1}) ≤ ϱ(s_i)`，且 `s_i ∉ 𝒞` 時嚴格——
`𝒞 = {(1,0,0), (4,0,0), (2,0,0)}`（Thm 4.9 的終端 3-循環）。

但其 Table 5 的 `(9,1,0)` 列（HTML 版核實的完整列）：

| State | Div t1 | Div t2 | Mul3 t1 | Mul3 t2 | Mul3 t3 |
|---|---|---|---|---|---|
| (9,1,0) | (9,0,0) | **(9,1,0)** | (7,1,0) | (8,1,0) | **(9,1,0)** |

含**兩個到自身的轉移**（Div 與 Mul3 各一）；§4.3 亦自列
`(8,1,0) ↔ (9,1,0)`（雙向邊均在 Table 5）與另兩條循環
`(6,0,0)→(3,0,0)→(0,1,0)→(5,1,0)→(6,0,0)`、
`(4,1,0)→(7,0,0)→(2,0,0)→(1,1,0)→(4,1,0)`。
`(9,1,0) ∉ 𝒞`，嚴格下降的 ℕ 值函數在自環上要求 `ϱ(s) < ϱ(s)`，矛盾。
其 Remark 4.10 稱這些循環「structurally harmless」，但除非另證 global
invariant 排除該轉移欄（正文無），Lemma 4.18 與 Table 5 不相容。
此外 Table 5 每列最多 2 個 Div 目標 + 3 個 Mul3 目標——局部後繼為**多值**
（依全域奇偶與下方進位），`δ^(k)` 寫法預設 δ 為函數，ϱ 的定義本身不良定
（Thm 4.9 第 1 款的「transitions deterministically」同此問題）。

### (b) Drift 僅平均為負，pointwise 有反例【腳本重現：已重現】

`w(n) = to(n)·log₂(3/2) − tz(n′)`。反例 **n = 11**：
`to(11) = 2`，`11 → 17 → 26`，`tz(26) = 1`，
`w(11) = 2·log₂(3/2) − 1 ≈ +0.170 > 0`（精確判定：`3² = 9 > 2³ = 8`）。
論文的「絕對不等式」`1 + tz/to > log₂(3/2)` 平凡成立但**不是** `w < 0`
的條件；所需為 `tz/to > log₂(3/2)`。奇數 `< 10⁵` 中 `w > 0` 者共
**14310 個**（非孤例；精確整數判定與浮點判定逐點一致）。
負性只在平均意義成立（其自報 `E[tz] ≈ 2.00` 為 "Empirically"），
即 Terras/Tao 平均漂移論證的自動機重述——其 Remark 5.15 實質自承。

### (c) 數位吸收歸納的 base case 循環【引文核對：已核實】

Lemma 4.14（Digit absorption）**證明的 base case（i = 1）**宣稱：
"the only symbolic states that may appear in position i = 1 are (1,0,0)
or (2,0,0)"。但其 Appendix C（HTML 版編號 Table 4）的 n = 13 軌跡表中，
`s₁` 欄 step 0 即為 `(1,0,1)`、step 1 為 `(4,0,0)`——自我反證
（`(4,0,0)` 屬終端循環但不在宣稱的集合；`(1,0,1)` 兩者皆非）。
Lemma 4.14 的敘述「每個數位位置終將永久歸零」等價於軌道終將停留於
個位以下——即 Collatz 猜想本身；歸納步又依賴「下方進位永久為零」
（其 Lemma 4.13），循環依賴。

### (d) 能量函數不沿軌道鏈接【腳本重現：已重現】

Lemma 5.13 比較的是「奇數點 → 乘法段結束」；除法段 f 回升。
軌道 9 → 7（全軌道 9→28→14→7 的奇數點；n₀ = 9 固定，忠於論文定義）：
`f(9) = 2 < f(7) ≈ 3.886`——奇數點序列上 f **上升**，
blockwise 下降不能複合成終止性。
